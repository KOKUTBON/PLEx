# Communication

KOKUTBON develops open technology for public benefit. Use repository issues for reproducible bugs and feature proposals, and Discussions for questions and design conversations.

- Usage, ideas and community questions: [Discussions](https://github.com/KOKUTBON/PLEx/discussions).
- Reproducible bugs and actionable proposals: [Issues](https://github.com/KOKUTBON/PLEx/issues).
- Implementation and review: focused pull requests with validation and decision rationale.
- Security vulnerabilities: [SECURITY.md](SECURITY.md); never disclose exploit details publicly.
- Conduct concerns: email [kokutbon@gmail.com](mailto:kokutbon@gmail.com) with subject `[PLEx] Conduct report`. Include links and context, and request an uninvolved reviewer if the concern involves a maintainer. The organization currently has a single technical maintainer; an independent escalation panel is not established.

Use respectful, specific language and synthetic examples. Do not post personal data, documents, credentials, biometric records, journal entries or confidential material in public spaces. Responses depend on maintainer availability; there is no guaranteed service level.
