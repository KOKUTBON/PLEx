# Repository data policy

Source distributions must not contain customer records, personal documents, facility layouts from deployments, credentials, operational exports, production logs or database dumps. Keep these in deployment-controlled storage with appropriate access and retention controls.

Tests and examples use synthetic inputs. Make synthetic identities and identifiers explicit; use reserved example domains and invalid account identifiers. Do not infer permission to redistribute material merely because it is publicly accessible. Document source, license and attribution for any third-party reference data before inclusion.

Before accepting a contribution, review text, images, document metadata, archives, generated artifacts and Git changes for sensitive material. Never attach real records to public issues or pull requests. Report accidental exposure privately to kokutbon@gmail.com; rotate exposed credentials and follow GitHub's sensitive-data removal process where history or cached references are affected.
