# Security Policy

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub Security Advisory
for this repository. Do not disclose vulnerabilities in public issues or pull
requests.

## Supported Versions

Only the latest release series is supported for security fixes. If you are
using an older version, upgrade to the latest release before reporting.

## Response Expectations

Reports are triaged on a best-effort basis. You will receive acknowledgement
and status updates as the issue is investigated.

## Private reporting contact

Email [kokutbon@gmail.com](mailto:kokutbon@gmail.com) with subject `[PLEx] Security report`. Include affected version/commit, reproduction using synthetic data, preconditions and impact. Do not include live credentials or personal data. This mailbox is the fallback while the repository is private or GitHub's reporting form is unavailable.

After publication, prefer [GitHub private vulnerability reporting](https://github.com/KOKUTBON/PLEx/security/advisories/new) when enabled. Acknowledgment and remediation depend on maintainer availability; no response deadline is guaranteed. Coordinate disclosure and fixes privately.
